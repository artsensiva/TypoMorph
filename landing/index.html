The first-release plan

Less interruption.
More control.

These are the requirements we are building toward. They are not claims that the current prototype is ready for everyday use.

01 / Local by design

Your typing stays yours.

Planned release processing uses transient memory, with no typed-text uploads, input logs or automatic telemetry. Account and payment services are separate from text processing.

02 / Careful correction

Change only what is safe.

Correct confident layout mistakes, leave uncertain text alone, and refuse protected or unknown fields. Manual correction and safe undo are part of the plan.

03 / Your preferences

Keep the controls close.

Choose supported layouts, pause correction, exclude applications and control optional sounds. Sounds will be off by default; autostart will require your consent.

A few things to know.

Can I install TypoMorph now?

Version 1 is not ready. Older prototype packages are not recommended for everyday use and do not meet the approved release requirements. Developers can inspect the repository and use its device-free simulator with synthetic text.

Does it use AI or send my writing to a server?

The approved product uses local layout detection and conversion. AI prompt improvement and spelling correction are outside version 1. The release must not transmit or persist typed content. This is a release requirement, not a privacy certification for older prototypes.

Will I need a browser extension?

Native browser coverage is the first goal. Extensions are conditional on demonstrated need; the existing extension code does not provide text correction.

Where can I follow development?

The development branch on GitHub records implementation, test evidence and remaining blockers. No newsletter signup or tracking script is needed.
